# Rise PulseBar — Quick Start Guide

Welcome to **Rise PulseBar**, an ultra-lightweight system monitor for macOS by **RISE Studio Labs**.

---

## Install

1. Open the DMG
2. Drag **Rise PulseBar** to **Applications**
3. Launch it — your metrics appear in the menu bar instantly

---

## Your Menu Bar

Once running, you'll see colored metrics in your menu bar:

| Color | Metric | What it measures |
|-------|--------|-----------------|
| Blue | **CPU** | Processor usage |
| Green | **RAM** | Memory usage |
| Orange | **DSK** | Boot drive storage used |
| Purple | **GPU** | Graphics processor usage |

The animated bar chart icon shows all four metrics as live-updating bars.

---

## The Dashboard

**Click** the bar chart icon to open the dashboard panel. It shows:

- CPU usage + sparkline history (60 seconds)
- GPU usage + sparkline history
- Memory (used / total)
- Disk (used / total)
- Swap usage
- Network download / upload speeds
- Top CPU-consuming process

**Drag** the "RISE PULSEBAR" header to move the panel anywhere on screen.
**Close** with the X button in the top-right corner.

---

## Display Modes

Right-click the bar chart icon to access the menu:

| Mode | Menu bar shows |
|------|---------------|
| **Minimal** | CPU only |
| **Standard** | CPU + RAM |
| **Full** | CPU + RAM + DSK + GPU |

The dashboard always shows everything regardless of mode.

---

## Settings

| Setting | Options | Where |
|---------|---------|-------|
| Mode | MIN / STD / FULL | Right-click menu or dashboard |
| Refresh Rate | 1s / 2s / 5s | Right-click menu or dashboard |
| Launch at Login | On / Off | Right-click menu or dashboard |

All settings save automatically and persist across restarts.

---

## Performance

Rise PulseBar is designed to be invisible to your system:

- **CPU:** ~0.3% idle
- **Memory:** ~45 MB
- **App size:** 8.9 MB
- **Startup:** instant

---

## Privacy

Rise PulseBar is **fully local**. It does not:

- Connect to the internet
- Collect analytics or telemetry
- Require an account or login
- Phone home for any reason

Your data stays on your Mac. Period.

---

## Requirements

- macOS 12.0 (Monterey) or later
- Apple Silicon or Intel Mac
